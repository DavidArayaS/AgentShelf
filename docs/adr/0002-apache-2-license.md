# Apache 2.0 license

Status: accepted architecture direction; implementation tracked in PLAN.md.

## Context

A separate proprietary Cloud product must remain possible.

## Decision

Use the unmodified Apache-2.0 license, attribution notices, DCO contributions and an explicit trademark exclusion.

## Alternatives considered

Copyleft; custom source-available terms.

## Consequences

Preserve notices and audit all dependencies; code licensing grants no trademark rights.
