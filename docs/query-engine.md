# Query engine

`searchProducts(catalog, query)` is the pure deterministic implementation. `MemoryQueryEngine` implements the asynchronous QueryEngine port, validates its catalog and supports atomic replacement. REST/MCP delegate to the same instance in CLI `serve`. It has no crawler, platform, connector or protocol dependencies; a private Cloud index can implement the public query contract.

Supported filters: normalized text, brand/category, merchant ID, typed attributes, variant properties, price/currency/availability, known shipping destination, sorting and bounded offset/limit. Exact BigInt fixed-scale comparisons avoid floating-point price errors. Explicit price filters and price sorting require currency. Related availability/price predicates match the same offer; variant predicates match the same variant. Unknown price or shipping destinations do not satisfy corresponding filters. Stable ID tie-breaking avoids locale-specific ordering. Results and merchant metadata are copies.

Text matching is lexical, case/accent insensitive and includes product name, description, brand, categories, attributes and selected variants' attributes. A documented small query grammar interprets numeric price bounds, size and in-stock phrases; explicit filters take precedence. See [search.md](search.md). Unsupported language remains lexical; there are no LLMs, embeddings, external inference services or fabricated facts. Relevance is deterministic, not an agent-ranking guarantee.

Canonical products returned as candidates retain all source offers/variants, including ones that did not match; clients must select a qualifying offer for comparison. Price sorting uses the least expensive matching offer. `getMerchant` exposes current source metadata, and optional `replaceCatalog` permits local acquisition to update shared REST/MCP search. Injected engines without replacement reject API activation with 409.

The reference engine scans local data and sorts matches. The diverse seeded benchmark measures normalization, validation, filtered search, variant search, engine construction and serialization at 100/10k/100k. Distributed retrieval, semantic models and cross-merchant intelligence remain private Cloud capabilities; they can consume the same canonical model and QueryEngine interface.
