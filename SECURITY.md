# Security policy

This project is pre-release and is not yet approved for production use. Security fixes target the current development branch until a supported release policy is announced.

Do not disclose exploitable vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository when enabled; otherwise contact a repository maintainer privately via their GitHub profile to arrange a confidential report. Do not include secrets or customer data. Maintainers must enable private reporting before public releases.

Include affected versions, reproduction steps, impact, and a minimal safe fixture. Never test against systems you do not own or have permission to assess. No response-time SLA is promised.

Remote commerce pages are hostile input. Follow PLAN.md's crawler threat model. No remote JavaScript execution or default telemetry is permitted.
